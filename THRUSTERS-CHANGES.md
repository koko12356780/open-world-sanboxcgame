# v0.9 Thrusters

Volt Aero Roadster now has two visible rear jet nozzles, soft smoke/vapor trails, animated jet cones, local light and a synthesized thrust loop. Hold W/Up to fire them while accelerating; flight hover keeps a lighter plume. No extra purchase is required for the Roadster's factory jets. Its existing acceleration and speed targets are unchanged.

Aurora RS gains a **Gas Thrusters** upgrade costing **2,500 coins**. Equip the Aurora, open **G > Workshop > Boost / Thrusters**, choose **Gas Thrusters**, and click **Buy**. They fire automatically with forward throttle. Release throttle to stop firing. Select the factory induction option to remove them; owned parts can be re-equipped for free.

The upgrade adds 40% acceleration and 10% top speed relative to the same engine/exhaust build. On an otherwise factory Aurora this gives a 330 MPH cap. It occupies the existing boost/induction slot, replacing a turbo kit rather than stacking with it. Existing engine/exhaust upgrades can still be used. Thruster sound is separate from engine and turbo sounds.

Other cars cannot buy or equip this Aurora-only part, including through invalid save entries. Owned parts and each car's equipped build are saved. Existing v0.8 saves continue to load without losing their cars, coins or known parts. A previous game version does not understand this new part; keep v0.9 selected while using Gas Thrusters.

Use a chase camera (C or V) to see the rear hardware and trails. Smoke remains visible in world space as the car moves. Reset clears the visual/sound state, and switching cars rebuilds the correct rear assembly. No fuel meter or new hotkey is added.

Install the provided update ZIP using **launcher v1.4 > Import Update**. Leave it zipped. It contains game data and license files only; the existing official Godot 4.6.1 Windows runtime is reused. The launcher, saved-data directory and engine version are unchanged.

All meshes, shaders and synthesized thrust audio are original. The cars and gas-thrust performance are fictional arcade designs.
