# Original synthesized driving sounds

These PCM WAV files were created for Open Streets using mathematical pulse,
harmonic and noise synthesis. They are original synthetic approximations, not
recordings of specific real cars. They use the project's MIT license.

For each cylinder count (4, 6, 8, 10, 12, 16), there are idle and loaded loops for
factory, muffler delete, straight pipe, sport and race exhausts. The game crossfades
idle/load, follows the shared RPM with playback pitch, applies exhaust loudness,
and adds boost whistle, blow-off, exhaust pops, road noise and impacts.

The main folder's audio-preview.wav is recorded from the actual game mixer.
Approximate sections, each about 2.5 seconds:

1. Factory inline-four + factory muffler.
2. V8 + muffler delete.
3. V8 + straight pipe + street turbo.
4. V16 + titanium race exhaust + twin turbo.

Each section revs up then releases the throttle. The recording uses external-view
volume; the cockpit is slightly quieter. The audio is fictional game sound design;
the modification stats are arcade balancing values.

Two additional harmonic loops, electric_idle.wav and electric_load.wav, give
the Volt Aero its own electric motor sound. There are 68 audio assets in this folder.

Streetlife adds tire_squeal.wav, an original synthetic tire friction loop. Its
volume follows burnouts and lateral slips, and it pauses with driving audio.
